# VistaDash Website

This repository contains the source code for the official homepage of the VistaDash application. The website is a simple, responsive, single-page design meant to introduce the app to new users and provide a link to the privacy policy.

## 🚀 How to View

To view the website, simply open the `index.html` file in your favorite web browser. No special server or build process is required.

## 📂 File Structure

The project is organized into the following files and directories:

-   `index.html`: This is the main landing page for the website.
-   `privacy.html`: A separate page containing the app's privacy policy.
-   `css/style.css`: The stylesheet that defines the visual appearance of the website, including the modern, warm theme.
-   `js/script.js`: Reserved for any future interactive functionality. It is currently empty.
-   `Images/`: This directory contains all the visual assets for the site, including the app icon and screenshots.
-   `README.md`: This file.

## ✨ Features

-   **Responsive Design:** The layout adapts to different screen sizes, from mobile phones to desktops.
-   **Modern UI:** Clean and modern design with a warm, inviting color palette.
-   **Informative:** Clearly presents the app's features and purpose.
-   **App Store Link:** Directs users to the app's page on the App Store.
-   **Privacy Policy:** Includes a comprehensive privacy policy as required by the App Store.
